# Françoise Martin | Professeur de français

Site vitrine pour un professeur de français, avec une landing page moderne, responsive et bilingue.

## Démarrage

```bash
npm install
npm run dev
```

Ensuite, ouvrez http://localhost:3000 dans votre navigateur.

## Production

```bash
npm run build
npm run start
```

## Stack

- Next.js
- TypeScript
- Tailwind CSS
